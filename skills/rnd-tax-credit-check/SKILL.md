사용자가 사업자등록번호나 시험기관명을 주고 연구개발비 세액공제 적격 여부를 물으면 이 워크플로우를 사용한다.

## 기본 원칙

1. 최신 법령과 공식 등록현황을 우선 확인한다.
2. 사업자번호만 주어진 경우 먼저 현재 기관명과 동일 법인 여부를 식별한다.
3. 민간 기업정보는 기관명 식별 보조용으로만 사용하고 적격 판단의 핵심 근거로 사용하지 않는다.
4. KOLAS 인정만으로 별표6 적격을 확정하지 않는다.
5. 기업부설연구소 보유만으로 외부 위탁기관 적격을 확정하지 않는다.
6. 결과는 '확인됨 / 적격 가능 / 추가확인 필요 / 해당 없음'으로 표현한다.
7. 적용 사업연도가 명시되면 반드시 그 사업연도에 적용되는 법령 버전을 확인한다.

## 조회 순서

### 1. 사업자번호 및 기관 식별
- 사업자번호를 숫자 10자리로 정규화한다.
- 정부·공공기관 공개자료에서 기관명, 주소, 과거 명칭, 법인 식별정보를 찾는다.
- 명칭 변경이 발견되면 동일 법인인지 명시한다.

### 2. 별표6 법적 기준 확인
- 국가법령정보센터에서 적용 사업연도의 조세특례제한법 시행령 제9조 및 별표6을 확인한다.
- 외부 위탁 연구개발비 관련 열거기관 중 다음 경로를 우선 검토한다.
  - 연구산업진흥법상 주문연구산업 또는 연구관리산업을 영위하는 기업
  - 한국표준산업분류표상 기술시험·검사 및 분석업을 영위하는 기업
  - 전담부서등 관련 요건이 적용되는 유형
  - 산학협력단 등 기타 별표6 열거기관

### 3. 전문연구사업자
- 연구산업진흥 관련 공식 신고/등록 현황을 검색한다.
- 단순히 연구 관련 사업을 수행한다는 사실과 '전문연구사업자 신고'는 구분한다.
- 확인되지 않으면 '미확인'이지 '미등록 확정'으로 단정하지 않는다.

### 4. KSIC
- 공식 KSIC 분류 및 사업자등록증 업태·종목을 우선한다.
- 기술시험·검사 및 분석업 영위 여부가 핵심이다.
- 단순 KOLAS 인정기관이라는 이유만으로 KSIC 요건 충족으로 간주하지 않는다.

### 5. KOLAS
- KOLAS 또는 국가기술표준원 공식 자료에서 현재 공인시험기관 인정상태를 확인한다.
- 인정번호, 기관명, 유효기간을 적는다.
- 사용자가 시험항목/규격을 제시하면 그 시험이 인정범위에 포함되는지 추가 확인한다.
- KOLAS 인정은 강한 보조증거이지만 별표6 자목의 KSIC 영위요건과 동일한 개념은 아니다.

### 6. 기업부설연구소
- KOITA 또는 공식 신고관리 자료를 확인한다.
- 연구소 보유 여부와 계약상 수탁기관 적격 여부를 분리한다.

## 결과 형식

항상 다음 표를 먼저 제시한다.

| 검토항목 | 결과 | 근거/확인사항 |
|---|---|---|
| 사업자번호 | | |
| 현재 기관명 | | |
| 전문연구사업자 | | |
| KSIC | | |
| KOLAS | | |
| 기업부설연구소 | | |
| 별표6 해당경로 | | |
| 종합 검토 | | |

그 아래에 다음 세 부분을 짧게 정리한다.

- **판단 근거**: 별표6 어느 항목과 연결되는지
- **추가 증빙**: 사업자등록증, 시험성적서, KOLAS 인정범위, 계약서, 연구과제 연결자료 등
- **주의사항**: 적격기관 여부와 해당 시험비 자체가 연구개발비인지 여부는 별도 판단임

## 판정 문구

- 공식 등록 + 별표6 기관유형 + 실제 용역범위까지 직접 확인: "요건 충족 근거가 확인됨"
- 기관유형은 유력하나 KSIC/인정범위/실제 수행업무 일부 미확인: "적격 가능성이 있으나 추가확인 필요"
- 핵심 등록정보 확인 불가: "현재 공개자료만으로는 판단 보류"
- 확인된 사실이 별표6 유형과 명백히 불일치: "확인된 범위에서는 해당 경로 적용이 어려움"

세액공제 가능 여부를 법적 확정판정처럼 표현하지 않는다.
