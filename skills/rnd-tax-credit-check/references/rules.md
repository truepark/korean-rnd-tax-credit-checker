# 판정 기준 요약

## 거래관계 우선판정
별표6상 외부 위탁기관 적격성을 보기 전에 해당 사업자번호가 사용자의 자기 회사 사업장인지 확인한다.
- 동일 법인 본점·지점·공장·연구소: 외부 위탁기관 판정 대상이 아님
- 별도 법인 계열사: 외부기관 검토 가능
- 거래관계 불명확: 계약서·세금계산서 발행주체·법인등록번호 추가 확인

## 사업자번호 정규화
- 사용자 입력값에 `-`, 공백 등 비숫자 문자가 있으면 모두 제거한다.
- rnd.or.kr 검색에는 숫자 10자리만 사용한다.
- 예: `353-88-00727` → `3538800727`.
- 정규화 결과가 10자리가 아니면 검색하지 않고 입력 오류로 처리한다.

## 기업부설연구소/전담부서 공식 확인
공식 URL: https://www.rnd.or.kr/user/infoservice/search5.do

개발자도구 Network에서 확인된 검색 방식은 동일 URL에 대한 `POST`이다.
- GET으로 검색페이지를 먼저 열어 세션/쿠키를 확보한다.
- `application/x-www-form-urlencoded` POST를 전송한다.
- 핵심 필드: `currentPage=1`, `s_yngugubn=3`, `save_s_yngugubn=3`, `excel_yn=N`, `s_type=CUSTNAME`, `s_custsuno1=<10자리 숫자>`, `save_s_custsuno1=<10자리 숫자>`.
- `save_s_custsuno1`에 이전 조회값이 남아 있더라도 구현에서는 현재 조회번호와 동일하게 덮어쓴다.
- 응답 HTML의 결과표에서 기업명, 연구소/전담부서명, 규모, 연구분야, 구분을 추출한다.
- POST 직접조회가 실행 오류일 때만 Playwright fallback을 사용한다.
- 단순 GET 쿼리스트링 `?s_custsuno1=` 방식은 공식조회 완료로 보지 않는다.
- 실제 POST/브라우저 검색 결과가 0건인 경우에만 `공식 검색 0건`으로 표시한다.
- 도구가 연결되지 않았거나 실행되지 않은 상태는 `미등록`으로 해석하지 않는다.

## 기타 판정 원칙
- 연구산업진흥법상 등록/신고 여부와 실제 연구 관련 사업 수행 사실을 구분한다.
- KSIC상 기술시험·검사 및 분석업 영위 여부는 실제 업종 증빙을 확인한다.
- KOLAS 인정은 강한 보조근거이나 별표6 자동충족으로 보지 않는다.
- 기업부설연구소/전담부서 보유는 외부 수탁기관 적격을 단독으로 확정하지 않는다.
- 기관 적격성과 시험비 자체의 연구개발비 해당 여부는 별도 판단한다.
