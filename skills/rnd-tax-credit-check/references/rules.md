# 판정 기준 요약

## 거래관계 우선판정
별표6상 외부 위탁기관 적격성을 보기 전에 해당 사업자번호가 사용자의 자기 회사 사업장인지 확인한다.
- 동일 법인 본점·지점·공장·연구소: 외부 위탁기관 판정 대상이 아님
- 별도 법인 계열사: 외부기관 검토 가능
- 거래관계 불명확: 계약서·세금계산서 발행주체·법인등록번호를 추가 확인

## 기업부설연구소/연구개발전담부서 공식 확인
공식 확인 출처는 기업부설연구소/전담부서 신고관리시스템의 연구소/전담부서 검색 페이지를 우선한다.
- 공식 URL: https://www.rnd.or.kr/user/infoservice/search5.do
- 사업자번호로 우선 검색한다.
- 검색 결과의 기업명, 연구소/전담부서명, 구분, 연구분야를 기록한다.
- 사업자번호 검색 결과가 없을 때만 기업명으로 보조 검색한다.
- 회사 홈페이지, 채용공고, 민간 기업정보만으로는 '공식 인정'으로 판정하지 않는다.
- 검색 결과가 없으면 '미보유'가 아니라 '공식 검색에서 미확인'으로 표기한다.
- 검색 결과의 구분이 '연구소'이면 기업부설연구소, '전담부서'이면 연구개발전담부서로 구분하여 표시한다.

## 기타 판정 원칙
- 연구산업진흥법상 등록/신고 여부와 실제 연구 관련 사업 수행 사실을 구분한다.
- KSIC상 기술시험·검사 및 분석업 영위 여부는 실제 업종 증빙을 확인한다.
- KOLAS 인정은 강한 보조근거이나 별표6 자동충족으로 보지 않는다.
- 기업부설연구소/전담부서 보유는 외부 수탁기관 적격을 단독으로 확정하지 않는다.
- 기관 적격성과 시험비 자체의 연구개발비 해당 여부는 별도 판단한다.
