# 공식 데이터 소스 설계

## KOLAS

확인 항목:
- 기관명
- 인정번호
- 소재지
- 인정상태
- 인정범위
- 정지/취소/휴업 여부

주의:
KOLAS 인정 자체가 조세특례제한법 시행령 별표6 적격기관을 자동 의미하지 않는다.

## 국가법령정보센터

확인 항목:
- 적용 사업연도의 조세특례제한법 시행령 제9조
- 별표6 문언
- 개정일/시행일

## 전문연구사업자

공식 등록 또는 신고 현황을 최우선으로 사용한다.
기관명과 사업자등록번호가 직접 매칭되지 않는 경우 법인명/주소 등 보조 식별자를 이용한다.

## KSIC

사업자등록번호만으로 공개 KSIC가 직접 조회되지 않는 경우 다음 순서로 근거를 취합한다.

1. 정부 공식 사업자/기업 데이터
2. 사업자등록증 업태·종목
3. 통계청 KSIC 분류표와 실제 영위업종 매핑

## 기업부설연구소

연구소 보유 사실과 외부 위탁기관 적격성은 별개로 판단한다.
계약 상대방, 연구소 운영주체, 실제 연구수행 장소를 함께 확인한다.
